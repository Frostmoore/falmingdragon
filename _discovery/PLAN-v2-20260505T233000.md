**WorkingMemoryService — metodi:**
```php
public function append(string $line): void
// Aggiunge $line + timestamp a WORKINGMEMORY.md
// Dopo append: conta token (approssimazione: mb_strlen($content) / 4)
// Se token > 10.000: rimuove le righe più vecchie una a una finché < 9.000
// Operazione atomica: lock via flock() sul file
// Crea il file se non esiste

public function read(?int $lastLines = null): string
// Legge tutto WORKINGMEMORY.md
// Se $lastLines non null: restituisce solo le ultime N righe
```

**Token counting:** euristica GPT-4: `(int) ceil(mb_strlen($text, 'UTF-8') / 4)`. Non c'è `tiktoken-php` nel vendor attuale — euristica sufficiente per una soglia di troncamento operativa. Aggiungere commento in codice che spiega l'approssimazione.

**Nuovi tool da aggiungere in `ToolExecutor::dispatch()` e `DefaultToolsSeeder`:**
- `working_memory_append` — parametri: `line` (string, required). Chiama `WorkingMemoryService::append()`. Non è dangerous.
- `working_memory_read` — parametri: `last_lines` (integer, optional). Chiama `WorkingMemoryService::read()`. Non è dangerous.

```php
enum RiskCategory: string
{
    case Bash               = 'bash';               // shell execution, artisan, composer, npm
    case FileDelete         = 'file_delete';        // eliminazione file, email in trash
    case DatabaseDestructive = 'db_destructive';   // DDL/DML distruttivi (DROP, TRUNCATE, DELETE senza WHERE)
    case GitPush            = 'git_push';           // git push, force-push, rebase pubblicato

```

**`RiskCategoryMappingSeeder`:** aggiornamento idempotente via `Tool::where('name', $name)->update(['risk_category' => $category, 'is_dangerous' => $dangerous])`. Registrare in `DatabaseSeeder` o eseguire standalone con `artisan db:seed --class=RiskCategoryMappingSeeder`.
